# 💡 개발 배경

기존 소개팅 서비스는 프로필 사진과 첫인상 중심으로 매칭이 이루어지는 경우가 많습니다.

**Unblur**는 외모보다 대화와 성향에 집중할 수 있는 환경을 만들기 위해 기획되었습니다. 사용자는 처음에는 블러 처리된 화면으로 대화를 시작하며, 대화가 진행될수록 상대방의 얼굴이 점차 선명하게 공개됩니다.

또한 연애 가치관 테스트, 성향 분석, 밸런스 게임, 질문 사전 기능을 통해 자연스럽게 대화를 이어가고 서로를 더 깊이 이해할 수 있도록 설계하였습니다. 이를 통해 외모보다 소통과 공감에 집중할 수 있는 새로운 소개팅 경험을 제공합니다.

# 📚 배운 점

- **WebRTC 기반 실시간 통신 구조 이해:** OpenVidu 등을 활용한 미디어 서버 연결 및 실시간 스트리밍 제어 흐름 학습
- **실시간 데이터 동기화:** 화상 통화 중 세션 상태 및 마이크/카메라 On/Off 상태를 실시간으로 동기화하는 경험 확보
