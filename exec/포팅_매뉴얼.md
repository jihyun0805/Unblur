# 프론트엔드 포팅 매뉴얼

## Gitlab 소스 클론 이후 빌드 및 배포할 수 있도록 정리한 문서

### 1) 사용한 런타임, 웹서버, 빌드 도구 등의 종류와 설정 값, 버전(IDE 버전 포함) 기재
- **런타임**: Node.js 20.9.0 이상
- **프레임워크**: Next.js (App Router)
- **언어**: TypeScript
- **스타일**: Tailwind CSS
- **패키지 매니저**: npm
- **기본 포트**: 3000
- **IDE**: IntelliJ IDEA 2023.3 이상 또는 VS Code 권장

### 2) 빌드 시 사용되는 환경 변수 등의 내용 상세 기재
- 환경변수 파일: `FE/.env.production` (레포에 포함)
- 로컬 실행 시 `FE/.env.local`을 생성하여 환경변수를 입력해야 함
- 로컬 기준 주요 환경변수:
  - `NEXT_PUBLIC_API_URL`
  - `NEXT_PUBLIC_WS_RTC_URL`
  - `NEXT_PUBLIC_WS_CHAT_URL`

예시(로컬):
```bash
NEXT_PUBLIC_API_URL=http://localhost:8080
NEXT_PUBLIC_WS_RTC_URL=http://localhost:8080/ws/rtc
NEXT_PUBLIC_WS_CHAT_URL=http://localhost:8080/ws
```

### 3) 배포 시 특이사항 기재
- 빌드 결과물: `FE/.next/`
- 실행 명령(프로덕션):
```bash
cd FE
npm install
npm run build
npm run start
```
- 포트 변경: `PORT` 환경변수로 변경 가능
- 프록시/라우팅: 운영 환경에서 `/api`, `/ws`는 백엔드/Nginx 프록시 설정에 따름

### 4) DB 접속 정보 등 프로젝트(ERD)에 활용되는 주요 계정 및 프로퍼티가 정의된 파일 목록
- 프론트엔드는 DB 계정/프로퍼티를 직접 사용하지 않음 (해당 없음)
