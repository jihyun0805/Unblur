14기_공통PJT_시연 시나리오_A705

1. 로그인
- 화면 우측 상단의 로그인 버튼 클릭
- 아이디와 비밀번호 입력 후 로그인

2. 빠른 매칭
- 화면 중앙에서 좌측에 위치한 ‘빠른 매칭’ 영역 설명
- ‘매칭 시작하기’ 버튼 클릭
- 권한 허용 팝업에서 카메라·마이크 권한 허용
- 우측의 ‘블러 단계 미리보기’를 클릭해 라운드별 블러 적용 방식 설명
- 최종 단계에서 ‘뷰티 필터’를 클릭해 필터 적용 화면 시연
- 회원가입 시 응답한 설문조사를 기반으로 유사도를 계산해 매칭됨을 설명
- 30초가 지나면 유사도와 관계없이 대기열에 있는 이성과 매칭됨을 설명
- ‘매칭 취소’ 버튼 클릭

3. 1:1 매칭
- 빠른 매칭 우측의 ‘1:1 매칭’ 기능 설명
- 현재 접속 중인 사용자에게 직접 매칭 요청을 보낼 수 있음을 설명
- ‘매칭 요청하기’ 클릭 후 권한 허용
- 활동 중인 사용자 목록에서 닉네임 클릭
- 프로필 확인 후 우측 상단 X 버튼으로 닫기
- 매칭 요청 전송
- 요청을 받은 사용자는 프로필 확인 후 수락 또는 거절 가능함을 설명

4. 매칭 화면 (화상 통화)
- 매칭 성사 후 대화 화면 진입
- 서로 간단한 인사를 통해 연결 상태 확인
- 상대방 역할의 사용자가 채팅 전송
- 좌측 상단의 마이크/카메라 버튼으로 ON/OFF 가능함을 설명
- 상대방의 마이크·카메라 상태도 확인 가능함을 설명
- 마이크를 끈 상태에서 채팅에 빨간 점이 표시되는 것을 보여주며 알림 기능 설명

5. 대화 기능
- 채팅 영역에서 ‘밸런스 게임’ 클릭
- 밸런스 게임 진행 방식 설명
- 20초간 대화가 없을 경우 질문 카드가 자동으로 등장하며,
  질문 사전에서 랜덤으로 선택됨을 설명
- ‘질문 사전’ 클릭
- 라운드별로 질문 주제가 다름을 설명
  - 1라운드: 관심사 중심 질문
- 질문 하나를 선택해 실제 질문 시연

6. 라운드 구조 설명
- 총 4라운드 구성
  - 1라운드: 5분
  - 2라운드: 5분
  - 3라운드: 10분
  - 최종 라운드: 시간 제한 없음
- 다음 라운드로 이동 시 서로의 동의가 필요함을 설명
- 우측 상단 ‘라운드 스킵’ 버튼을 눌러
  라운드별 블러 처리 차이를 시연

7. 매칭 종료 및 평가
- 우측 상단의 전화기 아이콘 클릭하여 통화 종료
- 선명도 평가 화면 진입
- 매칭 종료 후 상대방의 선명도를 평가할 수 있으며,
  선명도 점수는 상호 평가 기반으로 산정됨을 설명

8. 매칭 이력
- 우측 상단 네비게이션 바에서 시계 아이콘 클릭
- 매칭 이력 화면 진입
- 프로필 클릭
- 대화 종료 후 AI가 라운드별 대화를 한 줄로 요약해 제공함을 설명
- 우측의 채팅 버튼을 통해 매칭 이후에도 지속적인 대화 가능함을 설명

9. 연애 가치관 테스트
- 네비게이션 바에서 집 아이콘 클릭해 홈으로 이동
- 우측 하단 보라색 원형 버튼 클릭
- 연애 가치관 테스트 화면 진입
- 답변 선택 후 결과 화면 확인
- 내 연애 유형의 특징과 주의점 설명
- 스크롤 시 궁합 추천 영역 표시
  - 잘 맞는 유형 / 잘 맞지 않는 유형 확인 가능
- 유형 캐릭터 클릭 시 상세 설명 확인
- ‘매칭하러 가기’를 통해
  해당 연애 유형을 가진 접속 중 사용자에게 1:1 매칭 요청 가능함을 설명
